No more overlay over the log. The service runs inside a login shell in its folder. When the command exits, the log stays, a dim line says how it ended, and you get a prompt right there: fix it (bundle install, migrate, kill a stale pid), then ↑ ⏎ or Start runs the service command again in the same terminal. Stop sends Ctrl-C (then SIGTERM/SIGKILL if it hangs); the shell stays.
