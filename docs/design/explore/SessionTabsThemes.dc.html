Session colours that can’t be mistaken for task status, in every theme
Task status already uses the whole colour wheel (17 bright vivid colours), so hue alone can’t keep the two apart. They’re separated on three axes instead: material (status is bright ink: rails, dots, codes, lamps; a session is a flat, muted surface), shape (status is a thin rail or round dot; a session is a square tile carrying the tab number, so it replaces the number rather than adding a mark) and place (status lives in the session bar and lists; session tiles live on tabs and wherever a session is named). Each theme takes its session palette from its own world.
