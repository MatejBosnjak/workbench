Run PR in app

Workbench knows which frontend PR a session is about and which branch the app service runs. When they differ it offers one click: use the PR’s worktree if there is one, otherwise fetch and check out the branch in the base checkout, then pnpm i && pnpm start. Real PRs and worktrees from today.
01Status bar chip
Appears when the active session has a frontend focus PR. Detected from the session’s worktree branch, PR links in prompts or terminal, the linked task’s PRs, or gh pr commands.
