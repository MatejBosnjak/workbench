3 · Tinted tabs
Each tab is a coloured card: a soft fill of its colour with a stronger line on top. The current tab fills deeper, and the session bar takes the same tint, so the tab and its screen read as one piece, like Chrome tab groups or iTerm tab colours.
+ strongest: you find a tab by colour before reading anything. − loudest; the strip stops being “still at rest”, and the waiting glyph has to compete with the colours.
What changes elsewhere
Violet stays the app’s “needs you” colour outside the strip: the Needs-you counter, the +N badge and Focus keep it, and the identity palette leaves violet out so it can’t be mistaken for a waiting session. Running no longer gets blue on the tab (only ···), and failed no longer gets red (only the boxed !). Per-task colours (all three “Redesign contact form” sessions in one colour) are possible but would bring back the problem inside a task, so it’s one colour per session.
Pick: I’d go with 2 · chip (the same mark in every list) plus the current tab’s colour line from 1. Pick 3 if you want colour to do all the work.
