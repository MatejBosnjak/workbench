A · Say what differs
Words that every tab shares go; words that tell them apart stay. A dim repo prefix (fe / api / e2e, from the PR or cwd) replaces “API:”, “E:”, “Fix”. When two or more open tabs start with the same words, those words fold to a dim … and the tab shows its tail. “Claude Code” becomes the branch or folder, in italics so you know it’s not a real title. Long titles cut in the middle, keeping both ends.
Tabs size to their text (≤ 150px), so 10 fit instead of 8.
+ no new chrome, no colour; cheapest to build. − folded prefixes need the group in your head; tooltip carries the full title.

B · Group by task
Sessions on the same task sit together under the task’s name, like browser tab groups. The label carries the shared words once, so the tabs inside only need what’s different. A 2px underline in the task’s status colour runs under the group. Click the label to collapse it to one chip; a collapsed group with a waiting session shows the violet ●1. Grouping is automatic (task link), drag a tab out to ungroup.
+ chunks 12 things into ~5; mirrors how you think (per task). − tabs reorder themselves when a task gets linked; sessions without a task stay as loose as today (pairs with A).

C · Repo badges
A small coloured code before the title: fe teal, api amber, e2e blue, wb green, ~ grey outline (no repo). Colour gets found before reading starts, so “the api ones” are a glance, and the letters keep it readable without colour. Badges are fixed per repo, never violet (that stays “needs you”), and the same badge shows everywhere a session is listed, so the link is learned once.
+ preattentive, survives truncation, no reflow. − splits by repo, not by task (3, 4, 7 still look alike); adds colour to a deliberately quiet strip. Pairs well with A.

D · Session rail
Sessions move from the top bar to a left rail (toggle; the top bar keeps a “Sessions 14 ●2” place). Every session gets a full row: the whole title, wrapped if needed, and a second line with repo, branch and age. Rows sort into Needs you / Running / Idle, newest first inside each, so the one you want is usually in the first three rows.
Rail width is resizable (2px edge on hover, as the sidebars); collapsed it can show just badges and state marks.
+ no truncation, no overflow, nothing hidden; scales to 30 sessions. − costs ~270px of terminal width; positions change as states change (an option: keep manual order and only float Needs you).

E · Recall by content (⌃⇥ switcher + richer hover)
You often remember a session by what you last asked it, not by its title. ⌃⇥ opens recent sessions as cards, most recent first: title, state, branch, your last prompt and claude’s last line. Hold ⌃ and tap ⇥ to step, release to open, like the app switcher, so ping-ponging between two sessions is one keystroke. Typing filters across titles, branches and prompts.
The tab hover card gets the same contents (last prompt + last line + task + PR), replacing today’s title/cwd tooltip.
+ works however many tabs; uses memory you already have. − doesn’t make the strip itself clearer; overlaps ⌘K (could become ⌘K’s empty state instead).
Suggested combination
A + C on the strip (cheap, fixes the alike titles and the “Claude Code” pair, more tabs fit), E for jumping. B or D if you regularly run 10+: B keeps the top-bar model, D replaces it.
